El servidor devolvió una respuesta en formato JSON con un código de estado 200 OK (indicando que todos salió bien)
La respuesta esperada no es fija en su totalidad, incluye un mensaje de confirmación con los mismos datos que se le envié en los cuerpos de petición.
La petición request: El cliente envia esto al servidor
	JSON
	{
		"nombre": "Maria",
		"mensaje": "Hola comunidad"
	}
El procesamiento del código en el servidor recibe el objeto y extrae las variables donde:
req.body.nombre se convierte en "Maria"
req.body.mensaje se convierte en "Hola comunidad"
El response ejecuta el res.json y devuelve en el cliente
	{
  		"estado": "Datos recibidos",
  		"nombre": "Maria",
  		"mensaje": "Hola comunidad"
	}
